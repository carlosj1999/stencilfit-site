How to print a tattoo stencil at the exact size from an iPhone

Export a PDF sized for your paper, print it at 100% or Actual Size, then measure the output with a ruler. Run the test with the same printer, paper settings, and print workflow you’ll use for the tattoo.

Free printer calibration PDFs

Choose the file that matches your paper. Each sheet has horizontal and vertical reference lines marked 4 inches and 100 mm.

Download US Letter PDF Download A4 PDF

1. Set the size and export your stencil

In StencilFit, import your design, select the paper you’ll load in the printer, and set the stencil width in inches or centimeters. Check the finished size and whether the artwork needs to be mirrored for transfer. You can place several sizes of the same design on one sheet to compare them. Use Export PDF when you want to print the file from another app or device.

2. Print using AirPrint or your printer’s app

If the printer appears in the iPhone print sheet, use AirPrint. Check the paper size and look for Actual Size or 100% if your printer offers that setting. Turn off Fit to Page, Scale to Fit, or a similar setting when available. Apple’s AirPrint instructions

If the printer doesn’t appear, open the exported PDF in your printer’s companion app if it supports PDF import, or print it from a computer. Use the same paper size and Actual Size or 100% in that print dialog. If a print path gives you no scale control, test it with the calibration PDF before relying on it.

3. Measure before you print on transfer paper

Measure from the center of one long end tick to the other on a horizontal line and a vertical line. A 100 mm line should measure 100 mm, and a 4-inch line should measure 4 inches. Compare each line to its own label.

If either measurement is off, check the paper size and scaling settings, then print the test again. For a consistent mismatch, open Calibrate printer in StencilFit and verify the result with another print. Measure the finished stencil before you transfer it.
